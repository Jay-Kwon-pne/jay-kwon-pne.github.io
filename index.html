Claude Notifier

Claude Notifier is a personal automation tool used by a single user (Jay Kwon). When a long response is produced by the user's local AI assistant session, the tool saves the text as a Google Doc in the user's own Google Drive and sends the document link to the user's own KakaoTalk account as a notification.

How it uses Google data

  • Scope: https://www.googleapis.com/auth/drive.file only.
  • The tool can access only the files it creates itself. It cannot see or read any other files in Google Drive.
  • The tool runs only on the user's own PC. No data is sent to any third-party server operated by the developer.
