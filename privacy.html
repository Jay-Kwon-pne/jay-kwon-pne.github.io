Privacy Policy — Claude Notifier

Last updated: October 9, 2026

1. Who uses this app

Claude Notifier is a personal tool built and used only by its developer (Jay Kwon). It is not offered to the public.

2. Data accessed

  • Google Drive (drive.file scope): the app creates Google Docs containing text generated in the user's own AI assistant sessions, and sets their sharing to "anyone with the link can view" so the link can be opened from a phone. The app can access only files it has created.
  • KakaoTalk: the app sends a message containing the document link to the user's own KakaoTalk account ("send to me").

3. How data is stored

OAuth tokens are stored only on the user's local PC. The app does not operate any server and does not collect, sell, or share any data with third parties.

4. Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

5. Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Documents created by the app can be deleted from Google Drive at any time.
